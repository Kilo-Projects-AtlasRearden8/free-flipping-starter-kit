# GitHub Pages

This site is published as a GitHub Pages site at `dylanasdale.github.io/free-flipping-starter-kit/` (or similar).

## Build

No build step required. This is a static HTML/Markdown site:

- Open `index.html` in any browser
- Calculators run entirely client-side (no server, no API keys)
- Print via browser Print command
