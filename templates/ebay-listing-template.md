# eBay Listing Template

Copy the text below into your eBay listing and fill in the bracketed fields.
Written in plain English so any buyer can understand it.

---

**Title:** [Brand] [Item Name] — [Condition] — [Key Detail, e.g. Size / Model]

**Condition:** [New / Like New / Very Good / Good / Acceptable — be honest about wear]

**Condition notes:** [Describe any scratches, stains, missing parts, or wear. Include a photo of any flaws.]

**Brand:** [Brand name, or "Unbranded"]

**Model / MPN:** [Model number, if any]

**Size:** [Size, if clothing/shoes]

**Color:** [Color]

**Quantity:** 1

---

**Description**

What it is:
[One or two sentences. Example: "This is a men's size M [brand] [item], worn a few times, in good condition."]

What's included:
[List everything in the box. Example: "Item only. Box and charger not included."]

Condition and flaws:
[Be specific. Buyers trust honesty. Example: "Light scuffing on the corner. No cracks. Works fine."]

Measurements (if clothing, shoes, or furniture):
[Example: "Pit to pit: 22 inches. Length: 28 inches."]

Why I'm selling:
[Optional, one short sentence. Example: "No longer fits."]

---

**Photos**

Take 4–6 clear photos in daylight:
1. Front of the item
2. Back of the item
3. Close-up of any flaws
4. Close-up of the brand label / model number
5. All accessories included
6. Item next to a ruler or common object for size

---

**Shipping**

Ships within [1–2] business days after payment.
Ships via [USPS First Class / USPS Priority / UPS Ground].
Packed in [recycled / new] packaging.
[Domestic only / ships to the contiguous US / international on request]

**Returns:** [30-day returns / no returns — buyer pays return shipping]

**Payment:** PayPal / credit card through eBay checkout.

---

**Tips**

- Describe flaws before the buyer asks. Honest listings get better feedback.
- Use the brand name and model number in the title so buyers find your item.
- Price based on *sold* listings, not active listings. See `tips/pricing-tips.md`.
- Check eBay's current fee schedule before you list. Use `calculators/ebay-profit-calculator.html` to estimate your profit.
