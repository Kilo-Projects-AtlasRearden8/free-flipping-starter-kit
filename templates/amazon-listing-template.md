# Amazon Listing Template

Copy the fields below into Amazon Seller Central when you create a new listing.
Written in plain English. Amazon has strict rules — keep titles factual and avoid
claims you cannot prove.

---

**Product ID type:** [UPC / ISBN / GTIN / Exemption]

**Product ID:** [Barcode number, if you have one]

**SKU:** [Your own code, e.g. FLIP-001]

**Product name / title:** [Brand] [Item Name] [Key Detail, e.g. Size / Model / Color]

**Brand:** [Brand name, or "Generic" if unbranded and you have approval]

**Manufacturer:** [Manufacturer name, or "Generic"]

**Condition:** [New / Used — Like New / Used — Very Good / Used — Good / Used — Acceptable]

---

**Description**

[2–4 short paragraphs or bullet points. Plain English. No medical claims, no
"guaranteed" results, no pricing mentions.]

Example structure:
- What the item is and what it does
- Condition and what's included
- Key measurements or specifications
- Who it's good for

---

**Bullet points (search terms)**

- [Key feature 1]
- [Key feature 2]
- [Condition detail]
- [What's in the box]
- [Brand / model]

---

**Images**

Main image: white background, item only, fills 85% of the frame.
Additional images: flaws, labels, packaging, scale, item in use.

---

**Offer**

**Handling time:** [1–2] days
**Shipping:** [Ship yourself / Amazon FBA]
**Price:** [Based on sold/competing offers — see tips/pricing-tips.md]

---

**Tips**

- Amazon buyers search by brand and model. Put both in the title.
- Used condition descriptions must match Amazon's condition guidelines exactly.
- Price against current competing offers, and check your margin with
  `calculators/amazon-profit-calculator.html`.
- Amazon's referral and fulfillment fees change — check the current fee
  schedule before you price.
