# Sourcing Log Template

Track every item you source so you know what's actually profitable.
Print the Markdown version, or import the CSV into Google Sheets / Excel.

## How to use

- Add one row per item, the day you buy it.
- Fill in "Sold for" and "Sold date" when it sells.
- Net profit = Sold for − (Purchase cost + Fees + Shipping supplies)
- Review once a month. Drop items that consistently lose money.
